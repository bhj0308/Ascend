🚀 Tech Talent Platform: Product & Architecture Plan

1. Core Product Vision

Name: TalentFlow (working title)

Mission: Connect Korean-Canadian tech professionals and founders with global tech talent (starting Korea, expanding globally), with integrated employment support and cross-border payments.

Core Loop: Hiring company posts → talent applies/gets referred → employment contract generated → team collaborates → seamless cross-border payments.

3. Product Layers (MVP → Scale)

Layer 1: Core Marketplace (MVP - Phase 1: Weeks 1-6)

Focus: Korean-Canadian founders hiring engineers in Korea, IEC job seekers
Scope: Minimal but complete loop

Features:

✓ User Onboarding: Sign up as Founder/Engineer/IEC with 1-click auth (Google)
✓ Profile System: Basic profiles (name, role, skills, location, availability)
✓ Job Board: Founders post jobs (title, salary, role, visa sponsorship needed?)
✓ Browse & Apply: Engineers browse and apply to jobs
✓ Messaging: In-app chat between founders and engineers
✓ Referral System: "Refer a friend" button (send unique link)
✓ Knowledge Base: Public wiki with Korea-Canada employment basics (visa, tax, contracts)

Layer 2: Employment Tooling (Phase 2: Weeks 7-12)

Focus: Remove friction from hiring; make it legally safe

Features:

✓ Contract Templates: 1-click contract generation (Korea engineer → Canada company, vice versa)
✓ Compliance Checklists: "Hiring from Korea" → step-by-step checklist (tax, visa, EOR)
✓ Offer Letter Generator: Auto-fill offer with salary, start date, role, benefits
✓ Tax & Visa Quick Ref: Simple guides (IEC rules, T1135 for employers, Korean employment law)
✓ E-signature: Sign contracts in-app (via DocuSign or similar)

Layer 3: Payments & Remittance (Phase 2-3: Weeks 10-16)

Focus: One-click cross-border payments with context

Features:

✓ Payment Directory: "Pay engineer in Korea" vs. "Send money to family"
✓ Wise Integration: Embedded Wise API (low fees, real rates)
✓ Invoicing: Simple invoice system (especially for contractors)
✓ Payment History: Searchable log (for tax purposes)
✓ Currency Conversion: Real-time CAD ↔ KRW rates

Layer 4: Community & Support (Phase 3: Weeks 16-20)

Focus: Build network stickiness; reduce support burden

Features:

✓ Community Forum/Slack: Korean-Canadian tech professionals network
✓ Mentorship Matching: IEC workers matched with Korean-Canadian mentors
✓ Job Success Stories: "How I got hired" profiles (builds trust)
✓ Email Digests: Weekly "jobs near you," "mentors available," "tax deadline reminder"

Layer 5: Global Expansion (Phase 4: Post-MVP)

Focus: Same model for other countries

Features:

→ India, Philippines, Taiwan, China talent → Canadian hiring
→ Canadian freelancers → Remote work worldwide
→ Multi-country payroll (Deel integration as fallback for complex cases)

4. User Flows (MVP)

Flow 1: Founder Posting a Job

1. Sign up with Google (first-time: select "I'm hiring")
2. Complete profile (company, role, industry, hiring needs)
3. Click "Post a Job"
4. Fill form: title, salary range, skills, visa sponsorship?, # positions
5. Get auto-generated warning if hiring internationally ("Read: Korea employment guide")
6. Publish job
7. Job appears on board; get email notifications when people apply
8. Message candidates; share contract template; use in-app e-signature

Flow 2: IEC Worker Applying

1. Sign up with Google (first-time: select "I'm looking for work" + "IEC visa status")
2. Complete profile (skills, location, visa timeline, languages, availability)
3. Browse "Tech Jobs in Canada"
4. See filter: "Sponsor IEC? Yes" or "Canadian citizen required"
5. Apply to jobs matching visa status
6. Chat with founder; ask about visa support
7. Receive offer; sign contract in-app
8. Start work; get prompt to set up payment method (Wise link)
9. Receive first payment; gets reminder to file T1135 if assets > $100k

Flow 3: Mentorship Setup

1. IEC worker fills profile: "I'd like a mentor"
2. System suggests matching Korean-Canadian professionals
3. Mentor gets notification; can accept/decline
4. Monthly 1-on-1 meeting link auto-generated (Calendly or similar)
5. Built-in questions: visa questions, job search, culture adaptation

Database Schema (Core Entities)


Users
├─ id, email, auth_provider, created_at
├─ profile: { name, role, bio, location, avatar }
├─ user_type: enum(Founder, Engineer, IEC_Worker, Immigrant)

Jobs
├─ id, creator_id (founder), title, description, salary_min, salary_max
├─ skills: array, visa_sponsorship: bool, job_type: enum(Full-time, Part-time, Contract)
├─ created_at, status: enum(Open, Closed, Filled)

Applications
├─ id, job_id, user_id, status: enum(Applied, Reviewing, Offered, Rejected, Hired)
├─ created_at, updated_at, notes

Contracts
├─ id, job_id or application_id
├─ template_type: enum(Korea_Engineer_Canada_Co, Remote_Contractor, etc)
├─ terms: { salary, start_date, end_date, benefits, termination }
├─ signed_at, signature_status: enum(Draft, Pending, Signed)

Payments
├─ id, from_user_id, to_user_id, amount, currency, payment_type: enum(Salary, Remittance, Gig)
├─ status: enum(Pending, Processing, Complete, Failed)
├─ wise_transaction_id, created_at

Mentorships
├─ id, mentor_id, mentee_id, status: enum(Active, Completed)
├─ created_at, meeting_schedule

API Structure (FastAPI endpoints)


/auth
  POST /signup
  POST /login
  POST /logout

/profile
  GET /me
  PUT /me
  GET /:user_id

/jobs
  GET /browse (filters: skills, location, visa_sponsorship, salary_range)
  POST / (create job)
  PUT /:job_id
  DELETE /:job_id
  GET /:job_id/applications

/applications
  POST / (apply to job)
  GET /me (my applications)
  PUT /:application_id (status updates)

/contracts
  POST / (generate from template)
  GET /:contract_id
  PUT /:contract_id (e-signature)
  GET /templates

/payments
  POST / (initiate payment via Wise)
  GET /me/history
  GET /:payment_id/status

/mentorship
  GET /available_mentors (with filters)
  POST / (request mentorship)
  PUT /:mentorship_id (accept/reject)

/knowledge
  GET /guides (wiki articles)
  GET /guides/:topic

9. Go-to-Market: First 100 Users

Weeks 1-2: Closed Beta (30 users)

  • Target: Your personal network (Korean-Canadian founders, IEC friends, developer contacts)
  • Strategy: Direct outreach via KakaoTalk, email, in-person meetups
  • Goal: Find 5-10 founders willing to post jobs, 20-30 engineers to browse
  • Feedback: Weekly 1-on-1s; iterate on UX

Weeks 3-4: Warm Launch (100+ users)

  • Target: Korean-Canadian tech communities (church, cultural centers, tech meetups)
  • Strategy: Post in Korean-Canadian Slack/Discord channels, church bulletin boards, tech events
  • Message: "A job board for Korean tech people (hiring + working in Canada)"
  • Goal: 10-15 jobs posted, 100+ engineers browsing, first hires

Weeks 5-6: Expand Reach (500+ users)

  • Target: IEC Facebook groups, Korean community online forums (Daum cafe, Naver)
  • Strategy: Share success stories ("I got hired in 2 weeks!"), post in IEC groups
  • Goal: Network effects kick in; referrals grow; 30+ jobs, 500+ users

12. Key Risks & Mitigations

Risk Mitigation
People don't trust unproven platform for hiring Start with your network; use social proof (success stories, profiles with photos + reviews)
Employment law compliance is complex; liability Partner with 1 Korean-Canadian accountant early; have them review contracts + guidance
Network effects are slow to kick in Hand-curate first 50 users; actively refer jobs to engineers; incentivize sharing
Wise integration delayed or breaks Have fallback: Stripe for initial MVP; prioritize Wise integration after launch
Competitors enter (LinkedIn Jobs, Upwork, Deel) Our moat is Korean-Canadian community + Korea expertise. Lock in users with mentorship + trust
